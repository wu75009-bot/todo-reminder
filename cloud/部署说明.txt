云端守时器 · 腾讯云函数版（部署说明）
==========================

要解决的问题：电脑关机后，提醒仍然要能到手机。

为什么必须有云：
「到点响一声」这件事，得有人在那一刻真的执行一次。电脑关了，这台机器上
没有任何东西在跑，所以只能有一个云上的东西替你守着时间。

为什么不用 Cloudflare：实测 workers.dev 在你这条网络下完全连不上
（超时 10 秒），部署上去也同步不了，废掉。

为什么是腾讯云函数（SCF）：
· 国内直连，实测 0.17 秒响应
· 每月免费额度 100 万次调用 / 40 万 GBs，而每分钟跑一次一个月只用 4.3 万次，
  连零头都用不到，正常使用不会产生费用
· 只需实名，不需要充值


整体是怎么跑的
--------------------------------------------------
1. 电脑开着的时候，本地服务把「未来 7 天所有还没发的提醒」整份写进云函数代码
2. 云函数上挂了一个每分钟触发一次的定时器
3. 云函数每次醒来，只发「刚好在这一分钟内到点」的那几条，发完就睡
4. 电脑关机 = 本地服务不在 = 不影响上面第 2、3 步

每条提醒只发一次的原理：函数只在「到点后的 55 秒内」发送，而定时器 60 秒
才来一次，所以每条提醒天然只落在一个时间窗里，不需要记「发过没发过」。


需要你做的（就两步）
--------------------------------------------------
第一步：注册并实名
1. 打开 https://cloud.tencent.com 注册（QQ 号可以直接登录）
2. 按提示完成实名认证（免费，微信扫码 + 身份证）
3. 打开 https://console.cloud.tencent.com/scf ，点一下开通云函数服务

第二步：建一对 API 密钥给我
1. 控制台右上角头像 → 访问管理 → 访问密钥 → API 密钥管理
   （或直接打开 https://console.cloud.tencent.com/cam/capi）
2. 点「新建密钥」，会得到 SecretId 和 SecretKey
3. 把这两个发给我

密钥说明（请看清）：
· 我只把它写进本机的 data/config.json，不上传到任何地方
· 有了它，我才能替你在云上创建函数、改函数、加定时器
· 主账号密钥权限很大。如果你介意，可以在部署验证成功后，回控制台把这对密钥
  禁用或删掉；不过删掉之后，本地就没法再更新云端队列了，需要重新建一对
· 更稳妥的做法是用子账号密钥（只授 SCF 权限），需要的话我告诉你怎么建


部署完之后我怎么验证
--------------------------------------------------
1. 建一条 3 分钟后的提醒
2. 确认队列已经推上云（日志里出现「云端同步（腾讯云函数）：N 条在云端排队」）
3. 我把电脑上的服务停掉（模拟你关机）
4. 到点你手机应该照样收到推送

第 4 步响了，这条链才算真的不依赖这台电脑。


已知的边界
--------------------------------------------------
· 定时器 60 秒一次，所以到点最多晚 60 秒（比如 21:30:00 的提醒，21:30:40 才响）
· 云函数某一次执行失败，那一条会漏；但你下次开机时，本地会把 30 分钟内
  错过的提醒补发一遍，所以不会彻底丢
· 电脑长期不开机会导致队列过期，开机时会重新对齐一次
